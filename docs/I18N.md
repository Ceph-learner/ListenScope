# 国际化与多语言开发指南（I18N Guide）

ListenScope 支持四种界面语言：**简体中文 (`zh`)**、**English (`en`)**、**한국어 (`ko`)**、**日本語 (`ja`)**，翻译集中维护在 [`core/i18n.py`](../core/i18n.py) 与 [`core/i18n_catalog.py`](../core/i18n_catalog.py)。

## 1. 新增或修改界面文字

1. 禁止在 UI 组件中硬编码仅单一语言的可见文案；所有标签、按钮、提示与对话框文字均通过 `tr(key)` 获取。
2. 在 `core/i18n.py` 或 `core/i18n_catalog.py` 中同时补齐 `zh` / `en` / `ko` / `ja` 四个键。
3. 工程代号（如 `AUDIO_IN`、`CONFIG`）仅用于辅助小标题（eyebrow）或 tooltip，主标签与按钮保持简洁可读的本地化文案。

## 2. 新增一种语言

1. 在 `core/i18n.py` 的支持语言列表与语言选择器中注册新语言代码。
2. 为所有现有翻译键提供完整映射（不可留空或回退为未翻译占位）。
3. 在设置页语言切换与主界面最小宽度（`1093×566`）下验证文案无截断、无重叠。

## 3. 自动化检查

- `tests/` 中的 i18n 回归测试会在每次 CI（[`.github/workflows/tests.yml`](../.github/workflows/tests.yml)）中检查四语键集合一致性与缺失项，确保 `QT_QPA_PLATFORM=offscreen python -m pytest -q --tb=short` 全部通过。
