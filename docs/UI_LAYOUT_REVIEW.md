# ListenScope 界面方案评审

基线是草稿 PR #15 上的 PySide6 混音和练习界面。比较时复用同样的四条合成音轨、和弦行及 A/B 控件。原型顶部的「统一配色」用于只比较布局。

| 方案 | 工作流 | 1200 × 800 的取舍 |
| --- | --- | --- |
| A 工作台 | 音轨、分析、时间轴自上而下，和当前 Qt 工作流最接近 | 页面高约 920，需要纵向滚动。适合习惯现有布局的用户。 |
| B 双栏扒谱 | 左栏切换音轨，右栏读取和弦、MIDI 和鼓点，时间轴在下方横跨两栏 | 首屏可见四轨与 A/B，分析列较窄。建议作为默认布局。 |
| C 练习优先 | A/B 波形在上方放大，下方并排显示和弦与音轨 | 首屏能看到全部分区，轨道波形的横向空间较小。适合反复试听和逐段练习。 |

原型使用固定布局和短控件过渡。播放只推进游标，波形在切换尺寸和缩放时重绘。减少动效下关闭过渡并放慢游标刷新，暂停时停止游标计时。A/B 边界响应拖动与键盘。

三版经确认后在原生 Qt 实现并保留，B 默认。在「设置 / 系统状态 → 外观主题 → 界面布局」选择即可。布局和配色可独立选择。三版共用一个时间轴与混音实例，布局切换保留选区、缩放和页签。参考和主题规则见 [DESIGN.md](../DESIGN.md)。
