# 音乐与音频术语表（Glossary）

| 术语 | 说明 |
|---|---|
| **色度（Chroma）** | 将频谱能量折叠到 12 个半音音级（C, C#, D, ..., B）的分布向量，忽略八度差异，用于识别和弦与调性。 |
| **调性（Key）** | 一首乐曲或乐段所围绕的主音与音阶体系（如 `C major`、`A minor`），由 Chroma 分布与调性轮廓（如 Shaath / Temperley 1999）相关性估算。 |
| **和弦级数（Roman Numeral / Degree）** | 以当前调性主音为 `I` 级标注和弦功能（如 `I`、`IV`、`V`、`vi`），方便吉他 Capo 移调与扒谱迁移。 |
| **转位 / Slash 和弦（Inversion / Slash Chord）** | 低音不是根音的和弦记法，例如 `C/E` 表示以 `E` 为最低音的 `C` 大三和弦（第一转位）。 |
| **BPM（Beats Per Minute）** | 每分钟节拍数，用于衡量乐曲速度。 |
| **半速 / 倍速（Half-time / Double-time）** | 节拍检测中常见的八度/倍频歧义（如将 `120 BPM` 识别为 `60 BPM` 或 `240 BPM`），ListenScope 通过速度先验分布进行消歧。 |
| **音分（Cent）** | 音高微调单位，1 个半音等于 100 音分；`-50 ~ +50 cents` 用于显示当前音高相对标准十二平均律音名的偏差。 |
| **RTF（Real-Time Factor）** | 处理耗时与音频时长的比值；`RTF < 1.0` 表示处理速度快于实时播放（如 `0.2x`）。 |
| **分轨（Stem Separation）** | 通过 AI 模型将混音分离为独立音轨（如 2-Stem：人声/伴奏；4-Stem：人声/鼓组/贝斯/其他），便于单独扒谱或混音。 |
