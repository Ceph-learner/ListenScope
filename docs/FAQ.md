# 常见问题（FAQ）

### 1. 没有 NVIDIA 显卡能不能用？
**可以。** AI 分轨是可选功能，不依赖独立显卡的实时频谱、音准、和弦/调性/BPM 识别、120 秒 A/B 不变调慢放、节拍器以及 WAV 导出全部在 CPU 上运行，开箱即用。

### 2. 为什么要优先选择「进程捕获」？
进程环回捕获需要 Windows 11（Build ≥ 20348）；Windows 10 可以使用系统环回。进程环回只采集你指定的音乐播放器或浏览器进程的声音，**不会混入系统提示音、聊天软件语音或游戏音效**，从而让音准、和弦与分轨结果更干净，也无需安装虚拟声卡。

### 3. 首次打开遇到 Windows SmartScreen 警告怎么办？
由于本项目尚未购买商业代码签名证书，Windows 首次运行未经签名的可执行文件时会弹出 SmartScreen 保护提示。
- 请先对照 GitHub Release 中的 `SHA256SUMS.txt` 校验文件哈希（PowerShell：`Get-FileHash <文件名> -Algorithm SHA256`）。
- 确认哈希一致且文件来自官方 Releases 页面后，点击提示窗口中的 **「更多信息」→「仍要运行」**。

### 4. 点击捕获后没有信号或波形不动怎么办？
- 确认选中的播放器进程**正在实际出声**（未静音、未暂停）。部分播放器/浏览器存在多个子进程，请尝试下拉框中同名的其他进程，或先切换为 **「系统环回」** 确认声卡输出正常。
- 若在无声卡或 Linux 环境下测试，可使用 `python main.py --simulate` 启动模拟信号模式。

### 5. 提示内存偏低或 AI 分轨被拒绝怎么办？
为避免 8 GB 显存 / 16 GB 内存设备发生 OOM 崩溃，ListenScope 内置了三级内存护栏（5120 / 3072 / 2048 MiB）：
- 关闭浏览器多余标签页或其他占用内存/显存的程序后再试；
- 缩短选中的 A/B 片段长度（默认按 6 秒安全分块处理）；
- 若 AI 任务卡住，随时点击顶栏红色 **E-STOP** 或按 `Ctrl+Shift+E` 强制终止子进程释放显存。

### 6. 怎么彻底退出程序（托盘问题）？
若在设置中开启了「关闭时最小化到系统托盘」，点击窗口右上角关闭按钮只会将程序隐藏到系统托盘。要彻底退出，请**右键点击 Windows 任务栏右下角的 ListenScope 托盘图标，选择「退出」**。

### 7. 怎么卸载软件？配置文件和导出数据存在哪里？
- **配置文件与导出位置**：默认保存在软件**同级目录**（`settings.json`、`exports/`、`workspace_outputs/`、`logs/`），不向 `C:\Users\` 写入隐藏数据。
- **卸载安装版**：通过 Windows「设置 → 应用」或安装目录中的卸载程序卸载。**卸载过程会保留 `exports/` 目录**，避免误删你导出的音频和 MIDI；若不再需要，可手动删除软件目录。
- **卸载便携版**：直接删除解压目录即可（删除前请先备份 `exports/`）。

### 8. 捕获过程中切换耳机、音箱或修改 Windows 默认输出设备会中断吗？
在 **「系统环回」** 模式下，ListenScope 会自动跟随 Windows 默认播放设备变化并无缝重连到新的输出设备，**过程中保留已捕获的 120 秒环形缓冲与当前 A/B 循环区间**，无需手动停止或重新选区。（按进程环回捕获直接绑定所选播放器进程，同样不受输出设备切换影响。）

### 9. 在线检查更新会上传数据吗？可以关闭自动检查吗？
**不会。** 在线更新检查仅向 GitHub Releases 读取公开的发行版本元数据，不上传任何音频、配置、设备标识或遥测数据；下载更新包时会自动对照官方 `SHA256SUMS.txt` 校验完整性。你可以在 **设置** 中随时关闭自动检查更新。
