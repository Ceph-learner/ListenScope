# ListenScope 应用图标设计说明与竞品相似度比对 (v1.1)

## 1. 设计说明

ListenScope v1.1 应用图标保留原版（`docs/design/legacy/listenscope_v1.svg`）的核心构图与全部识别元素：
- **外形轮廓**：双切角（Chamfered）精密音频仪器机箱，体现本地实时测量/示波仪器的工程气质。
- **核心意象**：5 根居中示波/频谱柱（带峰值帽）、十字标定准星、底部状态条、棋盘格角标。
- **主色体系**：机箱深底 `#0B0D0F`（浅色主题配套 `master_light`），示波柱采用高辨识度荧光绿 `#CEFF18`、青蓝 `#77DCE4` 与信号绿 `#00A878`。
- **多尺寸适配**：
  - `master_dark` / `master_light`（5 根柱 + 细微扫描线 + 峰值帽）：用于 ≥ 40 px（`.ico` 的 40/48/64/96/128/256 px、窗口图标、关于页、社交预览图）。
  - `small_dark` / `small_light`（3 根加粗示波柱 + 加粗外框）：用于 16/20/24/32 px，确保任务栏小图标与资源管理器缩略图不糊。
  - `tray_white` / `tray_black`（单色矢量）：根据 Windows 注册表 `SystemUsesLightTheme` 自动切换，读不到时默认使用白色版。

## 2. 竞品图标逐一比对

比对维度：**外形轮廓**、**主色**、**核心意象**。

| 竞品 | 外形轮廓 | 主色 | 核心意象 | 相似度结论 | 差异化 / 调整方案 |
|---|---|---|---|---|---|
| **Moises** | 圆角方形 | 蓝绿/深蓝渐变 | 抽象 M 形声波/音轨 | **明显不同** | ListenScope 采用硬朗切角机箱与 5 柱频谱标定，无字母 M 造型。 |
| **Transcribe!** | 矩形/音符徽章 | 蓝灰/黄 | 音符与波形片段 | **明显不同** | ListenScope 为对称示波柱 + 十字标定，不含音符符号。 |
| **Audacity** | 圆形/无边框耳机 | 蓝耳罩 + 橙红波形 | 戴耳机的声波 | **明显不同** | ListenScope 无耳机元素，外形为切角硬件机箱。 |
| **QQ 音乐** | 圆形/圆角矩形 | 绿 + 黄音符 | 倾斜音符 | **明显不同** | ListenScope 主色含荧光黄绿 `#CEFF18` 与青蓝 `#77DCE4`，意象为示波频谱而非音符。 |
| **Spotify** | 圆形 | 绿底 `#1DB954` + 黑弧线 | 三道倾斜无线/声波弧线 | **明显不同** | 轮廓、色调（柠檬荧光绿 vs 森林绿）与意象（垂直频谱柱 vs 倾斜弧线）均完全不同。 |
| **Ableton Live** | 无边框/方形 | 黑/灰 + 白/红 | 4 竖条 + 4 横条网格（Session 视图） | **部分元素同属极简几何，但整体明显不同** | Ableton 为纯等宽黑白条纹矩阵；ListenScope 有双切角外框、峰值帽、十字准星与青/绿/黄渐变。 |
| **FL Studio** | 异形水果轮廓 | 橙红 + 绿叶 | 芒果/柿子造型 | **明显不同** | 轮廓与具象水果意象毫无重叠。 |
| **Spek** | 方形/无外框 | 紫-红-黄热力谱 | 倾斜频谱热力图 | **明显不同** | Spek 展示连续热力频谱图，ListenScope 为居中 5 柱离散示波仪。 |
| **Sonic Visualiser** | 圆形/波形框 | 深蓝/青灰 | 连续声波曲线与放大镜 | **明显不同** | ListenScope 为切角矩形 + 离散频谱柱，无放大镜与连续波形线。 |
| **Voxengo SPAN** | 方形插件徽标 | 深灰 + 橙/绿文字或频谱线 | 英文字符/连续频谱包络 | **明显不同** | ListenScope 无文字主标志，使用标志性双切角机箱与 5 柱峰值帽。 |

**总结论**：以上 10 款竞品中，**没有任何一款**与 ListenScope 在「外形轮廓 + 主色 + 核心意象」上构成相近或混淆风险，无需对已定稿的 `docs/design/icon/` 源文件做额外改动。
