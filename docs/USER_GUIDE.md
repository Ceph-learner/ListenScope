## 一、5 分钟快速上手

1. **启动软件**：双击 `ListenScope.exe`。**实时频谱、音准、和弦/调性/BPM 识别、120 秒 A/B 慢放与节拍器均无需显卡**，开箱即用。
2. **选择音源并捕获**：
   - 在顶部控制栏的音源下拉框中选择正在播放音乐的播放器或浏览器进程（如需要捕获整个系统声音，可切换为「系统环回」）。
   - 点击开始捕获按钮，主视图即可实时刷新波形、频谱与和弦分析。
3. **（可选）配置 AI 分轨与 MIDI**：
   - 点击右上角设置图标 → **AI 与 MIDI 环境**。
   - 若本机已有 PyTorch / Conda 环境，可点击「扫描本机 PyTorch 环境」；否则点击「一键自动配置 AI + MIDI」，等待完成后重启软件即可。

## 二、界面分区说明

| 界面区域 | 主要用途 |
|---|---|
| **顶部控制栏** | 切换音源、开始/停止捕获、主题明暗切换、打开设置与语言切换；右侧常驻 AI **急停（E-STOP）** 按钮，AI 运行时高亮变红，可随时点击或按 `Ctrl+Shift+E` 立即中止并释放显存。 |
| **左侧主视图标签页** | 包含 **频谱/音准**、**和弦/调性**、**分轨混音**、**波形/时间轴** 等视图，用于实时观察声音与控制 A/B 区间。 |
| **底部停靠栏（A/B 练习与节拍器）** | 显示最近 120 秒音频环形缓冲，支持拖拽设定 A/B 点、调整 `0.5x–1.25x` 不变调播放速度、管理 12 个书签、使用 Tap 节拍器与导出练习 WAV。 |
| **底部状态栏** | 实时显示版本号、当前音源与采样率、分析延迟（p50）、缓冲时长、CPU 占用与减少动效开关。 |

## 三、4 个典型使用场景

### 1. 扒贝斯线
1. 捕获一段音乐后，在底部时间轴选中需要扒谱的小节，点击 **AI 2-Stem** 或 **4-Stem** 分轨。
2. 切换到 **混音（Mixer）** 标签页，单独保留 **Bass** 轨或开启 **`0–24 dB` 贝斯独听增益**。
3. 观察 FFT-YIN 贝斯最低音（支持低至 `B0` / `E1`），配合 `0.75x` 慢放逐音听辨。

### 2. 找调与和弦进行
1. 切换到 **和弦/调性** 标签页，播放歌曲主歌或副歌约 10–15 秒。
2. 查看 12-bin Chroma 热图、当前识别的三和弦、罗马级数与 12 步和弦轨迹，以及右侧估算的调性与 BPM。
3. 若使用变调夹（Capo），可直接在界面中调整 Capo 格数查看移调后的和弦指法级数；也可打开 **24 调和弦练习** 弹窗本地试听并导出 `.mid`。

### 3. 慢速循环练习
1. 在底部 120 秒环形缓冲波形上拖拽选中需要反复练习的乐句（A/B 点），或用预设区间按钮快速截取最近 10s / 30s / 60s。
2. 将速度滑块调至 `0.5x–0.9x`（采用 WSOLA 算法，**慢放不变调**）。
3. 可保存最多 12 个练习书签，并开启节拍器与预备拍进行跟弹练习。

### 4. 导出 MIDI 到 Cubase
1. 完成 AI 分轨后，在混音页点击对应单轨的「转 MIDI」按钮；也可直接通过「打开单轨 WAV 转 MIDI」导入本地单轨音频文件。
2. 所有和弦、鼓点与单轨旋律 MIDI 均自动规范为 **Steinberg Cubase 兼容 SMF Type-0（`480 TPB`）**。
3. 在 `exports/` 目录下找到生成的 `.mid` 文件，直接拖入 Cubase 工程即可对齐编辑。

## 四、播放设备自动跟随与在线更新

### 1. 系统环回自动跟随默认播放设备
- 使用 **「系统环回」** 模式捕获整机输出时，若中途插拔耳机、切换音箱或修改 Windows 默认输出设备，ListenScope 会自动检测到默认播放设备变更并无缝切换到新设备继续捕获。
- 切换过程中**不会丢失已捕获的 120 秒环形缓冲，也不会重置当前设定的 A/B 练习区间**，可直接继续听音与循环练习。（若采用按进程环回模式，捕获绑定所选播放器进程本身，不受系统默认播放设备切换影响。）

### 2. 在线检查更新与哈希校验
- 在 **设置** 中点击检查更新（或启用启动检查）时，软件**仅从 GitHub Releases 读取公开的版本元数据**，不上传任何音频、配置或本地使用数据。
- 下载新版本安装包时，程序会自动对照官方 `SHA256SUMS.txt` 进行完整性校验；如不需要自动检查，可在设置中随时关闭该选项。
