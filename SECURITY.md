# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **ListenScope**, please **do not** disclose it in a public GitHub Issue.

Please report vulnerabilities privately through GitHub's **Private Vulnerability Reporting** feature on the repository's **Security** tab (`Security → Advisories → Report a vulnerability`).

When reporting, please include:
- A clear description of the issue and potential impact
- Steps to reproduce or a minimal proof of concept
- Your ListenScope version (shown in the footer or `pyproject.toml`) and OS version

We will review reports as promptly as possible and coordinate a fix before public disclosure.

## Supported Versions

Security fixes are provided for the latest minor/patch release on the `main` branch.
