---
name: project-bootstrap
description: Initialize evidence-based, portable AI development memory for an existing or new software repository.
---

Inspect applicable instructions, README, tracked source, entry points, dependency manifests, tests, branches, recent commits and tags. Inspect GitHub Issues, pull requests, Actions and releases using the authorized connection when available. Distinguish empty results from inaccessible sources, CI definitions from run results, and user requirements from observed behavior.

Use the kit bootstrap script to add missing entry points and project state structure. Review existing entrance files for integration and conflicting rules. Fill the generated state from evidence. Use existing README and docs as durable references. Add PROJECT_CONTEXT, ARCHITECTURE, REQUIREMENTS, DECISIONS or DEVELOPMENT only where existing material leaves a real gap. Cite paths, commits and run links, and label missing evidence. Preserve existing source, CI, tags, docs and unrelated edits. Install portable skills and audit the result.
