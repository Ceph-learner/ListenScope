---
name: project-audit
description: Audit repository memory for stale claims, conflicting agent instructions, dirty state and independently reproducible handoff evidence.
---

Check Git status and compare the recorded baseline against current code and commits. Verify project and test paths, link evidence, CI run and release claims. Inspect overlapping AGENTS, Claude, Gemini and Copilot instructions for conflicting or repeated rules. Use the kit structural audit when available.

Try reconstructing purpose, features, stable baseline, unresolved issues, test commands and next action using only repository material. Report each discrepancy with severity, evidence and a concrete correction. Identify unverifiable claims and systems you could not access. Audit does not authorize commits, releases or modifications by itself.
